API 文档

API 概述

Dots API 开放平台提供兼容 OpenAI Chat Completions 与 Anthropic Messages 格式的模型调用接口。使用平台创建的 API Key 完成认证后，即可选择对应协议端点调用 Dots 模型。

当前文档示例通过端点 https://note3-prev-api.askdiandian.com 访问，并在请求头中携带 API Key。

基础 URL
URL
复制
https://note3-prev-api.askdiandian.com
认证与请求头

每次请求都需要通过 api-key 请求头传入平台生成的 API Key。请勿将完整 Key 写入前端代码、URL、日志或公开仓库。

请求头	必填	说明
Content-Type	是	固定为 application/json。
api-key	是	在 API Keys 页面创建并妥善保存的完整 API Key。
默认限流值

RPM 和 TPM 均按单个 API Key 分别计算。RPM 表示每分钟请求数，TPM 表示每分钟 Token 数。

限流指标	默认值
RPM（每分钟请求数）	60 次/分钟
TPM（每分钟 Token 数）	1,500,000 Tokens/分钟
POST
/v1/chat/completions
OpenAI 聊天补全

根据输入的消息列表生成模型回复。当前 dots3-note-prev 的上下文窗口为 512K Token。接口支持文本、图片、视频和音频输入，以及工具调用、深度思考和流式响应。为便于直接对照输入与完整输出，以下示例统一设置 stream: false 并展示实际调用返回的 JSON；如需流式响应，可将 stream 设置为 true 并按 SSE 解析增量事件。

请求参数
参数	类型	必填	说明
model	string	是	要调用的模型名称，当前示例为 dots3-note-prev。
messages	array	是	按顺序排列的对话消息列表；content 可使用文本字符串或包含图片、视频、音频等内容块的数组。
stream	boolean	否	是否以流式方式返回结果；本页示例统一关闭，设置为 true 时需按 SSE 解析增量事件。
max_tokens	integer	否	本次生成允许使用的最大输出 Token 数，基础调用示例值为 1024；省略时由服务端默认策略决定。dots3-note-prev 的上下文窗口上限为 524,288 Token（512K），输入 Token 数与本参数设置的最大输出 Token 数之和不能超过该上限。
stop	array	否	指定一个或多个停止序列；模型生成到任一停止序列时结束输出，响应内容不包含停止序列。请使用字符串数组传入。
tools	array	否	当前请求可供模型选择的工具列表，具体结构见工具调用章节。
tool_choice	string | object	否	控制模型是否以及如何选择工具，可使用 none、auto、required，或通过对象指定函数；使用前需先通过 tools 声明工具。
chat_template_kwargs	object	否	模型生成行为的可选配置对象；可通过 enable_thinking 控制深度思考，具体说明见深度思考章节。
基础调用

最小文本对话示例，使用 system 和 user 消息发起请求，并一次性接收完整 JSON 响应。

输入示例
BASH
复制

  -H "Content-Type: application/json" \
  -H "api-key: YOUR_API_KEY" \
  -d '{
    "model": "dots3-note-prev",
    "messages": [
      {
        "role": "system",
        "content": "你是一个AI助手"
      },
      {
        "role": "user",
        "content": "你好，请介绍一下自己"
      }
    ],
    "stream": false,
    "max_tokens": 1024
  }'

视频输入

根据输入的消息列表生成模型回复，采用 Anthropic Messages 请求与响应格式。 当前示例模型 dots3-note-prev 的上下文窗口为 512K Token，输入 Token 数与 max_tokens 设置的最大输出 Token 数之和不能超过该上限。接口支持文本和图片输入、工具调用、深度思考，以及非流式 JSON 与 SSE 流式响应。

事件顺序
message_start：开始一条消息。
一个或多个内容块，每个内容块依次经历 content_block_start、一个或多个 content_block_delta 和 content_block_stop。
message_delta：返回停止原因和累计输出用量等消息级增量。
message_stop：当前消息流正常结束。

网络读取边界不等于 SSE 事件边界；客户端应以空行分隔事件，并按内容块 index 累积增量。

delta 类型	所属内容块	增量字段	说明
text_delta	text	text	追加文本。

字段	类型	说明

type	string	固定为 message。

content	array	模型生成的内容块数组。
stop_reason	string | null	模型停止生成的原因；流式响应在 message_delta 事件中返回。

常见停止原因
stop_reason	说明
end_turn	模型自然结束当前回复。
max_tokens	达到请求的最大输出 Token 数。
tool_use	模型请求调用客户端工具。

非流式响应通过 HTTP 状态码表示请求结果；流式响应应在收到 message_stop 后结束本次消息处理。

状态码	说明

400	请求参数或 JSON 格式不正确。
